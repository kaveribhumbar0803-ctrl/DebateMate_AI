# 🧠 DebateMate AI

> AI-Powered Debate Preparation & Practice Platform

DebateMate AI is an intelligent debate assistant designed to help students prepare for debates, explore both sides of an argument, practice their responses, and improve their debating skills.

## 🚀 Features

- 🤖 AI-generated debate preparation
- ⚖️ FOR and AGAINST arguments
- 🔄 Counterarguments and rebuttals
- 💡 Key debate points
- 🎤 Opening and closing statements
- ⏱️ 60-second debate practice timer
- 📊 Argument evaluation
- 📈 Relevance, clarity and reasoning scores
- 📝 Personalized feedback

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Python
- Flask
- Google Gemini AI
